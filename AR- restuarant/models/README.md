# 3D Models

Place your `.glb` files in this directory.

Required files:
- `burger.glb`
- `pizza.glb`
- `coffee.glb`

You can download free sample models from:
- [Poly Pizza](https://poly.pizza/)
- [Sketchfab](https://sketchfab.com/) (Make sure to convert to glb if needed)
- [Khronos Group Samples](https://github.com/KhronosGroup/glTF-Sample-Models)
